各风格核心设计参数规范 (Token Specifications)

1. 经典模式 (Classic)

  • • 核心质感: 纯色平板，原生嵌入
  • • 圆角规范: 4px - 6px 直角/微圆角
  • • 毛玻璃模糊: 无 (0px，CPU开销最小)
  • • 阴影与边框: 细描边 (1px)，经典VS Code底色
  • • 代表应用: VS Code 经典界面

2. 苹果液态玻璃 (Liquid Glass)

  • • 核心质感: 高通透毛玻璃、反光内高光
  • • 圆角规范: 14px - 18px 流畅大圆角
  • • 毛玻璃模糊: 28px saturate(190%)
  • • 阴影与边框: 半透白边 + 顶部高光 (inset 0 1px)
  • • 代表应用: macOS Sonoma / visionOS

3. 谷歌 Material 3 (M3)

  • • 核心质感: Tonal Palette 阶梯色调表面
  • • 圆角规范: 16px - 24px 大圆角，胶囊按钮
  • • 毛玻璃模糊: 无，完全依靠色彩明度层次
  • • 阴影与边框: 无生硬描边，多层软投影
  • • 代表应用: Android 14 / Pixel Material You

4. 微软 Fluent 2 (Fluent)

  • • 核心质感: 亚克力 (Acrylic) 透光、微光泽
  • • 圆角规范: 6px - 8px 精致紧凑圆角
  • • 毛玻璃模糊: 20px 轻度磨砂
  • • 阴影与边框: 1px 细微光泽边框 (StrokeSubtle)
  • • 代表应用: Windows 11 Fluent UI / Edge
